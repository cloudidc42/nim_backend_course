## 📚 เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ออกแบบมาเพื่อพาคุณจากผู้เริ่มต้น ไปสู่ระดับมืออาชีพด้าน Backend Development ด้วยภาษา Nim ซึ่งเป็นภาษาโปรแกรมมิ่งสมัยใหม่ที่ผสมผสานความเร็วระดับ C กับ Syntax ที่อ่านง่ายแบบ Python

### ทำไมต้อง Nim?
- ⚡ **ประสิทธิภาพสูง** - Compile เป็น Native Code, เร็วกว่า Go และ Java
- 🐍 **Syntax คล้าย Python** - เรียนรู้ง่าย, อ่านง่าย
- 🛡️ **Type Safety** - จับ Bug ตั้งแต่ Compile Time
- 🔧 **Macro System** - Meta-programming ทรงพลัง
- 📦 **Cross-platform** - รันได้บน Linux, macOS, Windows
- 🌐 **Backend Ready** - HTTP Servers, Database, APIs ครบ

## 🛠️ เครื่องมือที่ใช้ในหลักสูตร

```
Backend Frameworks:
├── Jester          - Express.js-like framework
├── Prologue        - Full-featured web framework  
├── httpbeast       - High-performance HTTP server
└── mummy           - HTTP/WebSocket server

Databases:
├── SQLite          - Built-in, zero config
├── PostgreSQL      - Production grade
├── MySQL/MariaDB   - Popular choice
└── Redis           - In-memory cache

Libraries:
├── norm            - ORM for Nim
├── jsony           - Fast JSON
├── jwt             - JSON Web Tokens
├── bcrypt          - Password hashing
└── dotenv          - Environment variables

DevOps:
├── Docker          - Containerization
├── nginx           - Reverse proxy
├── GitHub Actions  - CI/CD
└── Kubernetes      - Orchestration
```
